        "# README — Regressão Linear com Padronização de Dados\n",
        "\n",
        "## Objetivo\n",
        "\n",
        "Este código demonstra, de forma didática, como treinar um modelo de **Regressão Linear** para prever o **preço de casas** com base em algumas características do imóvel.\n",
        "\n",
        "As variáveis utilizadas são:\n",
        "\n",
        "- **m2**: área da casa em metros quadrados\n",
        "- **Quartos**: quantidade de quartos\n",
        "- **Banheiros**: quantidade de banheiros\n",
        "- **Idade**: idade do imóvel\n",
        "- **Distancia**: distância até um ponto de referência\n",
        "- **Preco**: valor da casa\n",
        "\n",
        "---\n",
        "\n",
        "## O que o programa faz\n",
        "\n",
        "O programa executa as seguintes etapas:\n",
        "\n",
        "1. Cria uma base de dados com informações de algumas casas\n",
        "2. Separa as variáveis de entrada e a variável de saída\n",
        "3. Padroniza os dados de entrada\n",
        "4. Treina um modelo de Regressão Linear\n",
        "5. Exibe os coeficientes aprendidos pelo modelo\n",
        "6. Calcula métricas de desempenho\n",
        "7. Faz a previsão do preço de uma nova casa\n",
        "\n",
        "---\n",
        "\n",
        "## Explicando passo a passo\n",
        "\n",
        "### 1. Criação da base de dados\n",
        "\n",
        "O código começa criando um dicionário com os dados das casas e depois transforma esse dicionário em uma tabela do tipo **DataFrame**, usando a biblioteca `pandas`.\n",
        "\n",
        "Exemplo da base:\n",
        "\n",
        "| m2 | Quartos | Banheiros | Idade | Distancia | Preco |\n",
        "|----|---------|-----------|-------|-----------|-------|\n",
        "| 120 | 3 | 2 | 10 | 1.0 | 400000 |\n",
        "| 180 | 4 | 3 | 5 | 0.5 | 550000 |\n",
        "| 90 | 2 | 1 | 20 | 2.0 | 300000 |\n",
        "\n",
        "Essa tabela representa os dados que o modelo vai usar para aprender.\n",
        "\n",
        "---\n",
        "\n",
        "### 2. Separação entre entradas e saída\n",
        "\n",
        "Depois, o programa divide os dados em duas partes:\n",
        "\n",
        "- **X**: variáveis de entrada, isto é, as características da casa\n",
        "- **y**: variável de saída, isto é, o preço da casa\n",
        "\n",
        "Em outras palavras:\n",
        "\n",
        "- o modelo recebe `m2`, `Quartos`, `Banheiros`, `Idade` e `Distancia`\n",
        "- e tenta prever `Preco`\n",
        "\n",
        "---\n",
        "\n",
        "### 3. Padronização dos dados\n",
        "\n",
        "Antes de treinar o modelo, o programa usa o `StandardScaler` para **padronizar** as variáveis de entrada.\n",
        "\n",
        "Padronizar significa transformar cada coluna para que ela fique com:\n",
        "\n",
        "- média próxima de **0**\n",
        "- desvio padrão próximo de **1**\n",
        "\n",
        "Isso é importante porque as variáveis estão em escalas diferentes. Por exemplo:\n",
        "\n",
        "- `m2` pode ter valores como 90, 120, 200\n",
        "- `Distancia` pode ter valores como 0.5, 1.0, 2.0\n",
        "\n",
        "Sem padronização, variáveis com números maiores podem influenciar mais o modelo apenas por causa da escala.\n",
        "\n",
        "### Como interpretar os valores padronizados\n",
        "\n",
        "Depois da transformação:\n",
        "\n",
        "- valor **positivo**: acima da média\n",
        "- valor **negativo**: abaixo da média\n",
        "- valor próximo de **0**: perto da média\n",
        "\n",
        "Exemplo:\n",
        "\n",
        "- `1.20` significa que aquele valor está acima da média\n",
        "- `-0.80` significa que está abaixo da média\n",
        "\n",
        "---\n",
        "\n",
        "### 4. Treinamento do modelo\n",
        "\n",
        "O programa então cria um modelo de **Regressão Linear** com `LinearRegression()` e treina esse modelo com os dados padronizados.\n",
        "\n",
        "A Regressão Linear tenta encontrar uma fórmula parecida com esta:\n",
        "\n",
        "\\[\n",
        "Preco = w0 + w1 \\cdot m2 + w2 \\cdot Quartos + w3 \\cdot Banheiros + w4 \\cdot Idade + w5 \\cdot Distancia\n",
        "\\]\n",
        "\n",
        "Onde:\n",
        "\n",
        "- **w0** é o intercepto\n",
        "- **w1, w2, w3...** são os coeficientes aprendidos\n",
        "\n",
        "Esses coeficientes mostram quanto cada variável influencia a previsão do preço.\n",
        "\n",
        "---\n",
        "\n",
        "### 5. Coeficientes do modelo\n",
        "\n",
        "Depois do treinamento, o programa exibe:\n",
        "\n",
        "- o **intercepto**\n",
        "- o **coeficiente de cada variável**\n",
        "\n",
        "Esses coeficientes indicam a influência de cada característica no resultado.\n",
        "\n",
        "#### Exemplo de interpretação:\n",
        "\n",
        "- coeficiente **positivo**: quando a variável aumenta, o preço tende a aumentar\n",
        "- coeficiente **negativo**: quando a variável aumenta, o preço tende a diminuir\n",
        "\n",
        "Como os dados foram padronizados, os coeficientes ficam mais fáceis de comparar entre si.\n",
        "\n",
        "---\n",
        "\n",
        "### 6. Métricas de desempenho\n",
        "\n",
        "O programa calcula três métricas principais:\n",
        "\n",
        "#### MAE — Erro Absoluto Médio\n",
        "\n",
        "O **MAE** mostra, em média, quantos reais o modelo erra por previsão.\n",
        "\n",
        "Exemplo:\n",
        "\n",
        "- `MAE = 15000` significa que, em média, o modelo erra cerca de **R$ 15.000**\n",
        "\n",
        "---\n",
        "\n",
        "#### RMSE — Raiz do Erro Quadrático Médio\n",
        "\n",
        "O **RMSE** também mede o erro, mas penaliza mais os erros grandes.\n",
        "\n",
        "Isso significa que, se o modelo errar muito em alguns casos, o RMSE sobe mais do que o MAE.\n",
        "\n",
        "---\n",
        "\n",
        "#### R² — Coeficiente de Determinação\n",
        "\n",
        "O **R²** mede quanto da variação do preço é explicada pelo modelo.\n",
        "\n",
        "Exemplos:\n",
        "\n",
        "- `R² = 1.0` → explica 100% da variação\n",
        "- `R² = 0.8` → explica 80%\n",
        "- `R² = 0.0` → não explica melhor do que usar a média\n",
        "\n",
        "---\n",
        "\n",
        "## Atenção importante sobre os resultados\n",
        "\n",
        "Neste código, as métricas são calculadas usando os **mesmos dados do treino**.\n",
        "\n",
        "Isso significa que o modelo é avaliado nos próprios dados que ele já viu.\n",
        "\n",
        "Como a base é muito pequena, pode acontecer de o modelo ajustar tudo perfeitamente, gerando resultados como:\n",
        "\n",
        "- `MAE = 0`\n",
        "- `RMSE = 0`\n",
        "- `R² = 1`\n",
        "\n",
        "Isso **não significa necessariamente** que o modelo é excelente para prever novos casos.\n",
        "\n",
        "Significa apenas que ele se ajustou muito bem aos dados usados no treinamento.\n",
        "\n",
        "Esse fenômeno pode indicar **sobreajuste**.\n",
        "\n",
        "---\n",
        "\n",
        "## 7. Previsão de uma nova casa\n",
        "\n",
        "Depois de treinar o modelo, o programa cria uma nova casa com valores como:\n",

        "- 7 anos de idade\n",

        "Depois disso, o modelo estima o preço dessa nova casa.\n",
